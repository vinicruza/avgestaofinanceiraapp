# Referências visuais

Posts/artes completos reais, fornecidos pelo usuário em 2026-07-31, para
referência de direção visual (composição, tom, uso de cor). Organizados por
marca em subpastas.

**Importante**: estes arquivos são material de apoio para calibrar
`brand/*.json` e futuros templates. Eles **não** são consumidos pelo
pipeline de render (`src/cli.mjs`) e **não** são logos — nenhum deles deve
ser usado como fonte de logo. Logos reais ficam em `../logos/<marca>/`.

## AV Gestão Financeira (`av-gestao-financeira/`)

- `post-3-numeros-antes-de-decidir.jpg` — fundo navy escuro, headline
  branca/azul, dashboard ilustrativo. Estilo mais próximo do template
  `instagram-feed-1080x1350` atual.
- `post-carrossel-7-7-financeiro-organizado.png` — fundo navy quase preto,
  CTA em vinho/bordô ("FALAR COM A AV"), slide final de carrossel.
- `post-contabilidade-x-gestao-financeira.png` — fundo claro/branco,
  infográfico comparativo, logo em cinza sobre fundo claro.
